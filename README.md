# 🐿️ FluffyWork (플러피워크)

> **직장인을 위한 화면 최상단 상주(Always on Top) 데스크톱 힐링 타이머 위젯**  
> 시차출퇴근제, 선택적 근로시간제, 자율출퇴근제를 위한 스마트 근무시간 관리 & 귀여운 다람쥐 마스코트와 함께하는 힐링 데스크톱 앱

## 📖 프로젝트 소개

**FluffyWork**는 매일매일 출퇴근 시간이 달라지는 유연근무제 직장인의 고민에서 출발했습니다.
* *"오늘 몇 시에 출근했더라? 몇 시에 가야 8시간 채우지?"*
* *"점심시간 1시간은 타이머에서 어떻게 빼지?"*
* *"정신없이 일하다가 칼퇴 시간 놓쳤네..."*

FluffyWork는 모니터 화면 한 켠에 항상 떠서(Always on Top) 실시간으로 퇴근까지 남은 시간을 계산해 주고, 귀여운 다람쥐 마스코트 **'뽀송이'**가 사용자의 근무 상태에 맞춰 함께 일하고 쉬어주는 사랑스러운 데스크톱 위젯입니다.

## ✨ 핵심 기능 명세

### 1. ⏰ 유연근무 출퇴근 & 스마트 자동 퇴근 시스템
* **요일별 맞춤 목표 근무시간**: 월~일 요일마다 다른 목표 시간(예: 월 8h, 수 6h, 목 9h, 금 7h 등)을 자유롭게 설정.
* **점심시간 (휴식) 자동 연동**: 지정한 점심시간(기본 `12:00 ~ 13:00`)이 되면 타이머가 알아서 **휴식(REST)** 모드로 전환되며 다람쥐가 식사를 합니다.
* **원클릭 출근 카운트다운**: 출근 버튼을 누르면 당일 출근 시각이 즉시 기록되고 퇴근 카운트다운이 시작됩니다.
* **🔔 퇴근 5분 전 사전 알림**: 남은 시간이 `00:05:00` 이하가 되면 알림 팝업 & 벨소리로 안내합니다:  
  *"퇴근 5분 전입니다! 슬슬 마무리 준비를 시작하세요 🏃💨"*
* **🎉 퇴근 시간 자동 완료 & 축하 연출**: 남은 시간이 `00:00:00`이 되는 순간 수동 클릭 없이 **자동으로 퇴근 완료 처리**, 신나는 팡파르와 화려한 폭죽(Confetti)이 터집니다!

### 2. 🐿️ 힐링 마스코트 ('뽀송이') & 커스텀 이미지
* **4가지 근무 상태별 반응형 일러스트**:
  * 💻 `FOCUS (근무 중)`: 미니 노트북으로 열일하는 다람쥐 & 모락모락 커피
  * 🥪 `REST (점심/휴식)`: 푹신한 방석에서 점심 도토리를 먹는 힐링 뽀송이
  * 💤 `PAUSED (일시정지)`: 수면 모자를 쓰고 베개에서 쿨쿨 자는 뽀송이 (Zzz)
  * 🎊 `COMPLETED (퇴근완료)`: 퇴근 가방을 들고 파티 모자를 쓴 채 만세를 부르는 뽀송이
* **나만의 커스텀 캐릭터 설정**:
  * 내 PC에 저장된 사진(JPG, PNG, GIF, WebP)을 직접 업로드하거나 외부 이미지 URL로 자유롭게 교체 가능.

### 3. 🗂️ 사이드 커스텀 기능 도크 (Dock)
위젯 좌측에 자주 쓰는 기능들을 최대 4개까지 원하는 순서대로 배치할 수 있습니다:
* ⏱️ **타이머 바로가기**: 실행 중 상태 표시 및 남은 시간 확인
* 🎨 **캐릭터 커스텀**: 마스코트 이미지 변경 모달
* 📝 **오늘의 Todo**: 체크박스 기반의 간단한 당일 업무 체크리스트
* 🏆 **업적 뱃지**: 첫 출근, 칼퇴 요정, 완벽한 주간 등 도전 과제 달성
* 📊 **주간 통계**: 요일별 근무 달성률과 주간 누적 시간을 직관적인 막대 차트로 확인

### 4. 📐 미니 뷰 (Mini Floating Bar) 모드
* 작업 공간이 좁을 때 우측 상단 축소 버튼(`⤢`)을 누르면 화면 우측 하단의 **초소형 가로형 미니 바**로 변신합니다.
* 미니 모드에서도 캐릭터 썸네일, 현재 상태 배지, 남은 시간 확인 및 일시정지/퇴근 조작이 가능합니다.

### 5. 🔒 100% 로컬 & 안심 개인정보 보호
* 모든 근무 기록 및 설정 데이터는 외부 서버로 전송되지 않으며, **오직 본인의 PC 로컬(`localStorage`)에만 안전하게 저장**됩니다.
* Web Audio API를 활용한 내장 사운드 신디사이저로 인터넷 연결 없이도 오프라인에서 모든 효과음이 작동합니다.

## 💻 직접 소스코드 실행 및 빌드하기 (개발자용)

### 사전 준비
* [Node.js](https://nodejs.org/) (v18 이상 권장)
* Git

### 1. 저장소 복제 (Clone) 및 패키지 설치
```bash
# 1) 저장소 복제
git clone https://github.com/ego99417/timer.git

# 2) 프로젝트 폴더로 이동
cd timer

# 3) 패키지 의존성 설치
npm install
```

### 2. 로컬 실행
```bash
# 데스크톱 앱(Electron + Vite)으로 실행 (추천)
npm start

# 웹 브라우저 모드로 개발 서버 실행
npm run dev
```

### 3. Windows 설치 파일(.exe) 직접 빌드
```bash
# Windows x64 설치형 및 포터블 패키지 생성
npm run dist
```
* 빌드가 완료되면 `release/` 폴더 안에 `FluffyWork Setup 1.0.0.exe` 및 `FluffyWork 1.0.0.exe` 파일이 생성됩니다.
